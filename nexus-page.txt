[center][b][color=#ff7700][size=5]Vertex Remover[/size][/color][/b][/center]

[b]Vertex Remover[/b] cleans up the dark, muddy vertex color painting baked into Skyrim's landscape, the same way the [url=https://github.com/Jampi0n/Skyrim-RemoveLandscapeVertexColor]Remove Landscape Vertex Color[/url] Synthesis patcher does, but at runtime. No patch plugin, no rerunning Synthesis every time you add, remove or reorder a landscape mod. It works on whatever landscape record wins in your load order, the moment the game loads it.

[b][color=#ff7700]What it does[/color][/b]
Every landscape vertex carries a color that gets multiplied over the terrain textures. Vanilla uses it to darken and tint the ground, which fights with modern texture replacers and leaves blotchy patches everywhere. Vertex Remover brightens those colors as the land loads, using the patcher's default settings: a gentle lift on normal ground, and a much stronger one on snow so snowy slopes stay clean white. It is a small SKSE plugin with no plugin file and nothing to configure.

[b][color=#ff7700]Compatibility[/color][/b]
[list]
[*]Works with any landscape mod, since it reads whatever record your load order ends up with.[/*]
[*]Safe with [url=https://github.com/hakasapl/SmoothTerrain]Smooth Terrain[/url] and [url=https://github.com/hakasapl/TerrainHelper]Terrain Helper[/url]. It never touches the code either of them hooks.[/*]
[*]Remove the Synthesis Remove Landscape Vertex Color patcher from your Synthesis setup and regenerate. Running both brightens the terrain twice.[/*]
[*]Distant terrain LOD keeps the vertex colors it was generated with.[/*]
[/list]
